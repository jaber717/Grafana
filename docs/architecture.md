## Responsibilities

| Component | Owns |
|---|---|
| This repository | dashboards (JSON), folders, datasource *definitions*, the playlist, pinned versions, deploy/verify/backup/rollback tooling |
| grafana-01 | the running Grafana, its database, plugin files, datasource *secrets* (encrypted in the database) |
| jaber717/Akvorado | the ClickHouse side: tables, retention, the `grafana_ro` user, the firewall rule that admits only 192.168.1.194 |
| Zabbix LAB | the `grafana-ro` account and the data behind the NOC dashboards |

## Dashboards

* **NOC** (`dashboards/noc`, datasource Zabbix): `noc-wan-overview` and `noc-device-health` keep their six fixed WAN-link panels / router wall (item-ID mode of the Zabbix plugin) in a collapsed row and add the **universal selection** (site, device type, device, interface, direction, metric — read from Zabbix host groups and items, nothing hard-coded), KPI cards, the five-state device table and metric explorers. Generated by `tools/monitoring/` from the frozen v1.0.1 JSON; see [UNIVERSAL-SELECTION.md](UNIVERSAL-SELECTION.md).
* **NetFlow** (`dashboards/netflow`, datasource ClickHouse): read Akvorado's rollup tables (`flows_1m0s`, `flows_5m0s`, `flows_1h0m0s`) chosen by time range, and the raw `flows` table only for IPs/ports/conversations, capped to 24 h. A *Data scope* variable (default "Real only") hides the synthetic demo exporter `::ffff:247.16.14.11`. They share the NOC selectors (site / device type / device from Zabbix; the hidden `exporter` set maps a device to its `ExporterName`) and separate configured, observed, active, idle and no-data exporters; *Platform Health* keeps platform, collector and exporter state apart. Source of truth is the committed JSON; `tools/netflow/generate.mjs` reproduces it (`tests/check-generator.sh`).
* Playlist **NetFlow NOC Rotation** cycles the five NetFlow dashboards every 45 s for a wallboard.

## How state flows

`tools/export-live.mjs` (capture) → Git → `scripts/apply.mjs` (API, idempotent) → Grafana. `scripts/verify.mjs` closes the loop (read-only drift detection). `scripts/backup.mjs` / `restore.mjs` give a content rollback; `*-lxc.sh` give a host-level rollback (database + config + package version).

## Identifier policy

Everything is matched by **uid** (dashboards, folders, datasources) or **name** (playlists). `id` and `version` are instance-specific and are removed from the stored JSON and ignored in comparisons.
